# Contributing to WEB_GUARD_AI

Thank you for your interest in contributing to WEB_GUARD_AI!

## Getting Started

1. Fork the repository.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/rajeshkannaj7-ai/WEB_GUARD_AI.git
   ```
3. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development Guidelines

- Follow existing code style and naming conventions.
- Never commit `.env` or sensitive API keys. Use `.env.example` as a template.
- Test your changes locally before submitting a PR.
- Write clear, concise commit messages following standard conventional commits.

## Pull Request Process

1. Ensure the build passes locally (`npm run build` in `frontend/`).
2. Push your changes to your fork.
3. Open a Pull Request targeting the `main` branch.
4. Describe your changes clearly in the PR description.
