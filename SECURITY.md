# Security Policy

## Supported Versions

Only the latest version of WEB_GUARD_AI receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within WEB_GUARD_AI, please follow responsible disclosure guidelines:

1. **Do not** open a public issue on GitHub.
2. Report the vulnerability privately by contacting the maintainers or via GitHub Security Advisories.
3. Provide details including:
   - Description of the issue
   - Steps to reproduce
   - Potential impact
   - Any suggested mitigations

We take security threats seriously and will acknowledge receipt within 48 hours and work on a prompt resolution.
